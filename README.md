# Financial Statement Analysis Using Excel

## Project Overview
This project analyzes the financial performance of a sample company using Microsoft Excel.

## Objectives
- Analyze revenue, expenses, and net profit.
- Calculate financial ratios.
- Compare yearly financial performance.
- Identify trends in profitability and expenses.

## Tools Used
- Microsoft Excel
- Financial Ratio Analysis
- Data Visualization

## Key Financial Metrics
- Total Revenue
- Total Expenses
- Net Profit
- Net Profit Margin
- Revenue Growth

## Expected Outcome
A structured financial analysis with calculations, findings, and recommendations.

## Dataset
This project will use illustrative sample financial data for learning purposes.
